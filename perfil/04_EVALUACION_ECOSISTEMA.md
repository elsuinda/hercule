## 2. Evaluación proyecto por proyecto

### 🤖 OSINT-bots (cazar bots y trolls) — *núcleo de Hercule*
Tu proyecto de hunting de bots con OSINT + código abierto (Twint, Sherlock, Maltego,
Gephi), más la charla de Ekoparty, **es literalmente el corazón de la identidad Hercule.**
Es investigación con método, open source y divulgación. Recomendación: que las
publicaciones y el repo de esto pasen a firmarse como Hercule. Es el mejor caso de uso.

### 🌐 Owltech + GeoIP — *fuente de inteligencia propia*
La herramienta de geolocalización/enriquecimiento de IP que montaste en
`owltech.com.ar/api/geoip/` no es solo un producto comercial: **es una capacidad OSINT
propia**. En la metodología Hercule (Fase 2, capa "infraestructura") entra como fuente
de enriquecimiento que no depende de terceros. Owltech como blog puede ser también el
canal de divulgación de Hercule.

### 🗂️ tuarchivo / i-hate-pdf — *soporte operativo*
No son investigación, pero **sirven al método**: censura de archivos (blureo, tachado de
datos sensibles) e informes brandeados son exactamente lo que necesitás para publicar
casos anonimizados. El módulo de "censura de archivos" de tuarchivo es, de hecho, una
herramienta forense de anonimización. Vale integrarlo al flujo de Hercule.

### 🔬 Script forense PowerShell / caso Drupal — *pedigree técnico*
Tu script forense para cuentas comprometidas en Windows Server y el caso de defacement
Drupal (MITRE T1491.001) son la **evidencia de que el método ya lo aplicás**. Hercule no
inventa nada nuevo: le pone nombre y forma a algo que ya hacés bien.

### 🏢 Líderes Consultores — *aplicación profesional*
Como Jefe de Seguridad Electrónica, el método Hercule aplica a investigaciones internas
y a clientes. Acá **no se publica**: se usa el proceso de 6 fases y el formato de informe,
pero firmado con la marca de la empresa y a tu nombre como supervisor.

### 🛰️ CICAT / Sinergia Cibernética — *frontera, fuera de alcance*
Confidencial. Hercule, como identidad pública, **no toca esto**. Mención solo para dejar
explícito el límite: el método mental puede ser el mismo, pero nada de ese ámbito se
publica ni se asocia a la marca pública.
