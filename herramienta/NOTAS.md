# HERCULE — Fase C: la herramienta (preparación)

*Esta carpeta está reservada para la Fase C: tomar una herramienta que ya tenés en
GitHub, mejorarla y rebrandearla bajo Hercule. Acá quedan las notas para arrancar
esa sesión sin perder tiempo.*

---

## Qué necesito saber para empezar

1. **Cuál herramienta.** El enlace del repo de GitHub (ej. `github.com/elsuinda/...`).
2. **Qué hace hoy.** En una frase, su función actual.
3. **Qué querés mejorar.** Funcionalidad nueva, rendimiento, UX, documentación, o todo.
4. **Lenguaje/stack.** Python, PowerShell, etc.

---

## Qué le vamos a aplicar (rebrand Hercule)

Cuando definas cuál es, el plan base es:

- **Estética Hercule:** si tiene interfaz (web o TUI), paleta negro/verde/naranja,
  el emblema como logo/icono, la firma Hercule.
- **Encabezado/banner** con el emblema ASCII o el logo según el tipo de herramienta.
- **Suite de documentación completa** (tu estándar): README, instrucciones de uso,
  `.gitignore`, logo, archivo de icono.
- **Firma de software** personalizada por acción, sin tildes, con
  `resultado guardado en [ruta]` donde corresponda, cerrando con la firma.
- **Versión portable + estándar** si aplica al tipo de herramienta.
- **Encuadre en la metodología:** dejar claro en qué fase del método "células grises"
  encaja (recolecta, analiza, etc.), así suma al ecosistema y no queda suelta.
